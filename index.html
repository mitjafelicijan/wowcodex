World of Warcraft Codex

A collection of tools, reference and resources for World of Warcraft 1.12.1.

  • Texture Explorer - Browse and preview interface textures.
  • API Reference - Addon API Documentation.
  • Events Reference - System Events and Payloads.
  • Library - Browse and read in-game books.
